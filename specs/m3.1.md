# M3.1 — Accurate professional profile and skills UI

M3.1 maintains one versioned effective profile with explicit professional, project and learning evidence. Only accepted local facts determine classification and technology duration. Employer, client, paid engagement and production attribution require their own evidence and are never inferred from projects or technology use.

The profile reads the approved local resume, application-answer bank and cover letter through the ignored document manifest. It stores bounded field-level references and hashes, never raw private text in Git or audit logs. User-confirmed facts override older wording. The answer bank is never a recruiter attachment and the canonical portfolio-free resume remains the default.

Schema v10 adds immutable profile revisions and non-destructive links from parser proposals to exact user-confirmed facts. A linked proposal remains in its original `PENDING` state until the user explicitly accepts, edits or rejects it. Extraction confidence never becomes approval, and the global resume review state remains false while unresolved proposals exist.

The dashboard groups canonical professional skills into Frontend and Architecture, AI Application Engineering, Backend and Data, and Quality, Delivery and Leadership. It shows technology duration, evidence counts, professional AI summaries, the stored resume filename/version and review progress. Detailed parser provenance is collapsed under accessible details.

M3.1 rescoring uses the same effective profile for import matching, discovery ranking and recommendations. Application packets receive new immutable generated versions when profile provenance changes; prior user edits and Gmail draft records remain untouched.
